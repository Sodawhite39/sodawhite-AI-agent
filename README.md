# sodawhite-AI-agent

## AI Agent 通俗学习全书

![AI Agent 通俗学习全书封面](assets/cover.png)

这是一套写给没有 AI 和编程基础的成年读者的学习文章。起点是一位八十岁读者提出的要求，遇到英文、公式和代码也不要跳过，要用能听懂的话讲清楚。

苏打白 Dev 根据李博杰的[开源原书](https://github.com/bojieli/ai-agent-book)整理与通俗改写。第二到第十章按原书 2.0 目录编排。本仓库是学习改写版，保留主要知识主题，重新组织解释、教学例子和配图，不能替代原书的完整数学推导与全部配套实验。

每章的英文会解释全称与含义，公式会讲符号并做小算例，代码会逐行解说。可以先读懂程序，不需要先买 API 额度或 GPU。教学例子明确标注为假设或模拟，避免把示例数字当成真实产品数据。

每章最后有自测题与折叠答案。先自己回答，再展开参考答案。文章写完说明教材已产生，掌握程度仍要由读者真实的回答和实践证明。

## 配图与源文件

第一章原有图保存在 `assets/ch01/`。第一章补充和第二至十章各有三幅新教学图，共三十幅，另有全书封面。正文显示 PNG，同名 SVG 可放大并编辑；图文数据位于 `illustrations/chNN.json`，图意说明位于 `illustrations/prompts/`。图与真实测试截图严格区分。

新教学图沿用第一章的白底中文信息图方向，采用代码渲染以保证术语和箭头准确。封面使用 AI 生成；所有插图都属于教学示意，不是产品界面或真实实验凭证。

## 制作与检查

本次交付的检查范围与限制见[验收记录](verification.md)。十二段安全 Python 示例已实际运行，图片与本地阅读链接已检查。原书的训练、联网操作、机器人与研究实验没有据此宣称复现。

已有正文与配图直接可读，不需要安装软件。下面的命令只供维护教材时使用，Python 3 检查与合卷无第三方依赖，重新渲染配图需要 Node.js 20 和 Sharp。

```sh
python3 scripts/check_book.py --run-examples
python3 scripts/build_book.py
npm install
npm run diagrams
```

渲染图上的中文还需要系统安装中文字体，如思源黑体。更换字体可能改变字形与宽度，应重新做视觉检查。

制作过程使用中文改稿与文章插图 skill，帮助控制来源、阅读顺序和图文对应。生活类比服务于理解，模型学到的是计算规则与统计关系，不能把类比里的人的意识或记忆直接套给模型。
