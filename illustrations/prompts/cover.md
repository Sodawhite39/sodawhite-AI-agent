# 全书封面

图片用途为书籍封面，AI 生成，不是实验截图。

沿用现有第一章白底、蓝橙绿配色的 editorial 教学插图方向。横版、大标题、高对比、温和克制。一位银发成年女性坐在书桌前阅读资料并检查任务，桌上有打开的书、任务清单与电脑。人物保留成年人的尊严与主动思考，不采用幼儿课本风格。

右侧以少量图形说明理解、上下文、工具行动与结果核验。封面准确写“AI Agent 通俗学习全书”和“苏打白 Dev”。不使用品牌 Logo、收益承诺、科幻机器人或复杂细小文字。

生成后检查标题文字、人物形象与阅读布局。封面中的概念顺序是阅读导览，正文中的 Agent 循环和反馈由详细教学图说明。
